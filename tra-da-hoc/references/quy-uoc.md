# Quy ước chung của khoá Trà Đá

## Chỗ lưu cố định
| Thứ | Tên | Tạo thế nào |
|---|---|---|
| Chỗ lưu kết quả chữ | **Sổ tay Trà Đá**: nơi lưu lại cả quá trình học, có sẵn trên web tại mrtrada.com/goi/so-tay (cần đăng nhập, tự lưu, đồng bộ). Không dùng chat, Google Docs hay app Ghi chú làm sổ tay. | Không cần tạo: đăng nhập và mở Sổ tay (cách dùng ở mrtrada.com/goi/thao-tac-so-tay-va-thu-muc). Mỗi bài một ghi chú `Bài <số> - <tên bài>`: mở đúng ghi chú, dán kết quả vào. Lấy lại: mở lại ghi chú đó, hoặc bấm Mở bài gốc để về bài. |
| Thư mục file và ảnh nộp bài | **Tra-Da-Bai-Lam** trong Tài liệu (Documents) | Mac: mở Finder, vào Documents, nhấn chuột phải và chọn New Folder. Windows: mở File Explorer, vào Documents, nhấn chuột phải, chọn New, rồi Folder. Ảnh chụp màn hình đặt tên bắt đầu bằng số bài, ví dụ `1.3-du-an.png`. |
| Dự án học | **Trà Đá - Học AI** | Tạo ở bài "Tạo project cho từng mảng việc". Trên claude.ai: Projects, rồi New project. Trên chatgpt.com: thanh bên, New project. |
| Dự án theo việc thật | **Việc - <tên mảng>** | Ví dụ `Việc - Bán hàng`. Mỗi mảng việc một dự án. |
| Thư mục agent | **~/hoc-agent** | Tạo ở bài cài Claude Code hoặc Codex (level 2). |

## Chat mới hay chat cũ
- Mỗi bài bắt đầu bằng **chat mới**. Đã có dự án thì mở chat mới bên trong dự án **Trà Đá - Học AI**.
- Sửa hay hỏi tiếp về cùng một kết quả thì dùng **chat cũ**: gửi tiếp ngay bên dưới câu trả lời.
- Việc khác hẳn thì mở chat mới. Để chung một chat, AI dễ lẫn thông tin.

## Dán vào đâu
- **Ô chat**: ô nhắn tin ở giữa hoặc dưới cùng màn hình, bấm mũi tên tròn để gửi.
- **Terminal**: Mac bấm Command + Space, gõ Terminal. Windows bấm phím Windows, gõ PowerShell. Muốn vào đúng thư mục: gõ `cd ` (có dấu cách), kéo thư mục vào cửa sổ, bấm Enter.
- **Claude Code**: Terminal đang mở Claude Code, ô nhắn có dấu `>`.
- **Instructions của dự án**: mở dự án, bấm Instructions (Claude: Set project instructions), dán vào, bấm Save.
